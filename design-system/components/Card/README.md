A card is a `surface` panel with a 1px `border` (or `rule` when not interactive), `radius-md`, `pad-card-y` × `pad-card-x`, and no shadow at rest.

- Heading in `card` (serif); a `label` kicker above it carries the maturity grade.
- Body in `body`, secondary lines in `ink-2`.
- Hover lift (`shadow-hover`) only when the whole card is a link.
