The primary button is the one copper fill in a view: `copper` ground, `on-copper` text, `radius-sm`, `pad-button-y` × `pad-button-x`, `control-min` tall, `control` type.

- One primary per view. Everything else is a text link (`copper`, underline offset 3px, an arrow glyph for a cross-section link).
- Focus: 2px `copper-ring` at 3px offset. Hover: transition background and transform only, at 0.15s.
- Disabled: 40% opacity, `not-allowed`.
